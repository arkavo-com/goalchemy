# SDK documentation site

Generated by `goalchemy docs -format site`. Use Node 24 and the pinned pnpm version:

```sh
pnpm install
pnpm check
pnpm dev
pnpm build
pnpm preview
```

The first install creates `pnpm-lock.yaml`; commit it and use `pnpm install --frozen-lockfile` in CI. Development serves at localhost:4321. Production output is `dist/`, including Pagefind search. Host that static directory on GitHub Pages or another static host. Set `site` and, for subpath hosting, `base` in `astro.config.mjs` before publishing. There is no Goalchemy-specific hosting requirement.

Edit the homepage, navigation, theme, and additional guides. Regenerating into this directory preserves scaffold customization and unrelated files. Generated reference pages live under `src/content/docs/api/`; edit Go comments and regenerate these pages instead of editing them manually. Modified generated pages are protected from overwrite. `.goalchemy-docs.json` records ownership and hashes; retain it for safe updates and stale-page cleanup.

`public/api.json` is the schema-versioned catalog for custom API browsers. All references use stable source symbol IDs; native declarations come from the same emitters as library builds. Markdown pages link types, methods and packages and work independently of this template when generated with `-format markdown`.

The reference describes the compiler-generated facade. Handwritten host adapters or SDK packaging layers can expose additional APIs that need separate documentation. Source comments may describe a larger Go API than any one native facade. Target availability is reported explicitly; a target that rejects this API has its reason listed in the reference index.
