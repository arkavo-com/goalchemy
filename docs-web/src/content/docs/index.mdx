## One source of truth for your SDK

Keep parsing, validation, protocols, and business rules in one typed codebase. Goalchemy lowers ordinary `.go` files through a typed intermediate representation, then emits source and the runtime each target needs.

<Pipeline />

<CardGrid>
  <Card title="Ordinary Go source" icon="document">
    Use the Go toolchain to write, run, and test your source. The compiler checks a defined subset and reports unsupported constructs before emission.
  </Card>
  <Card title="Semantics that travel" icon="puzzle">
    Preserve integer widths, byte strings, value copies, aliasing, errors, and cooperative tasks across target languages.
  </Card>
  <Card title="Behavior you can verify" icon="approve-check">
    Runtime contracts and differential tests compare generated programs with native Go. Reproducible output records its linked contracts in a manifest.
  </Card>
  <Card title="Native host capabilities" icon="setting">
    Use native crypto, HTTP, clocks, and logging through explicit capability boundaries. Keep pure logic in shared source.
  </Card>
</CardGrid>
